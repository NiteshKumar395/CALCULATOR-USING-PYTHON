# CALCULATOR-USING-PYTHON
A simple basic calulator program using python language for two variables.
# Features
- Addition ( + )
- Substraction ( - )
- Multiplication ( * )
- Division ( / )
- Floor divison ( // )
- Modulo ( % )
- Exponential ( ** )
- Handles divison by Zero
# Requirments
Python 3.14 installed on your device
## How to Run
1. Clone this repository:
   \bash
   git clone - https://github.com/NiteshKumar395/CALCULATOR-USING PYTHON.git

2. Navigate into the project folder:
   \bash
   cd calculator.py

3. Run the program:
   \bash
   python calculator.py

   (On some systems you may need `python3` instead of `python`)

4. Follow the on-screen prompts to enter two numbers and an operator.
